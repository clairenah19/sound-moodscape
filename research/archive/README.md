# Archive

Early material kept for provenance. Nothing here is read by the app or by any
script — it is superseded working material, retained because it documents where
the project's numbers originally came from.

- `korea_provinces.docx`, `korea_provinces2.docx` — the original province data
  sheets (population, density, English-speaker estimates, average temperature,
  safety index, nature highlights). These are the source behind the *first*
  mood-score formula's four terms. That formula was replaced on 2026-08-30 by
  the official-statistics Activity Proxy documented in `out/Log.md`, so these
  are no longer current — but they are the record of what the earlier scores
  were built from.
- `Screenshot 2026-08-09 … .png` — an annotated page of the City Mood &
  Character report, with a handwritten mark on the "two axes" passage. The
  clean version is `research/Moodscape_City_Mood_Character_Report_EN.pdf`;
  only the annotation is unique to this file.
