# Moodscape — Suno prompts for all places

Generated directly from the app's data + `buildSunoPrompt()` logic, so this always matches what
you'd see in each place's "Generate real music with Suno" panel. Grouped by region, in map order.

**Workflow per place:** copy the prompt → paste into Suno as an instrumental (no lyrics) →
download the MP3 → rename it to the exact filename shown → drop it in the `audio/` folder next
to `index.html`. See the "How to add songs" section at the bottom for details.

## How to add songs after generating them in Suno

A Suno **share link** (`suno.com/song/...`) is a webpage, not an audio file — pasting it
straight into the app won't play anything, since the browser can't treat an HTML page as a
sound source. There are two ways to actually get the song playing on the site:

### Option A — download the MP3 and drop it in the `audio/` folder (recommended)

This is the reliable path and needs no API key, no CORS workarounds, nothing external.

1. In Suno, open the song (from your Library/Workspace).
2. Click the **`...`** (triple-dot) menu on the song → **Download** → **MP3**.
3. Rename the downloaded file to the **exact filename** listed under that place above
   (e.g. `jeju-do__hallasan.mp3`).
4. Move it into the `audio/` folder next to `index.html` on this Mac:
   `/Users/claireyunhanah/Desktop/sound/audio/`
5. Reload the page and open that place — it detects the file automatically and plays it
   for real (the waveform will react to the actual audio). No code changes needed.

Repeat per place. You don't have to do all of them at once — any place without a file just
falls back to the built-in synth preview, so the site keeps working while you fill these in
gradually.

### Option B — paste a hosted URL (skip if you're not hosting the files yourself)

If you instead upload the MP3s somewhere with a real public audio URL (e.g. your own web
host, S3, etc. — not a Suno share link), open `index.html`, find this line near the top of
the `<script>` block:

```js
window.SUNO_TRACKS = window.SUNO_TRACKS || {};
```

and add an entry per place, keyed by the same filename base (no `.mp3`, no `audio/` prefix):

```js
window.SUNO_TRACKS = {
  "jeju-do__hallasan": "https://your-host.example.com/hallasan.mp3",
};
```

### Why not just paste the Suno link directly?

Suno has no official public API, and their song page isn't a raw media URL — it's a full
webpage with a player embedded in it, usually loaded behind protections that block a plain
`<audio>` tag from playing it directly (CORS). Downloading through Suno's own official
**Download** button and hosting the file yourself (Option A) is the dependable route; there
are third-party "Suno downloader" sites that claim to extract a direct link from a share URL,
but I'm not recommending those — most look like they violate Suno's terms of service and some
are ad-laden in ways worth being cautious about. Use Suno's own Download button instead.
